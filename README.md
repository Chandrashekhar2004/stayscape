🏡 StayScape
Full-Stack Travel Stay Booking Platform

StayScape is a modern full-stack web application inspired by platforms like Airbnb.
It allows users to explore accommodation listings, create and manage their own listings, write reviews, and securely authenticate using user accounts.

✨ Features
🔐 User Authentication & Authorization
🏠 Create, view, edit and delete property listings
🖼️ Cloudinary image upload and storage
⭐ Add and delete reviews
👤 User-specific listing ownership
🔍 Search destinations
⚡ Server-side form validation
🚨 Custom error handling
🔒 Protected routes and authorization
📱 Responsive user interface
☁️ MongoDB Atlas database
🚀 Deployed on Render
